# java-shareit
Данный проект представлиет собой сервис для шеринга вещей. Создавался этот проект с целью закрепления изученного мной материала:  
- Spring Data Jpa: базовые концепции и настройка  
- Транзакции в Spring и работа со свойствами транзакций
- Mock тестирование
- Работа с MockMvc фрейворком для написания тестов веб слоя
- Работа с тестированием в SpringBoot
